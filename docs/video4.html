chatgpt-codex客户端使用方法

按顺序完成下载、注册、安全设置与登录，即可正常使用 ChatGPT / Codex 客户端。

打开 ChatGPT 网页版 客户端下载 返回首页
01

视频教程

按视频步骤完成下载、注册与登录，看完即可上手。

02

下载（微软应用商店下载）

打开 Windows 自带的「Microsoft Store 微软应用商店」，搜索 ChatGPT（含 Codex），点安装即可。

Microsoft Store 搜索 ChatGPT 官方安装包
商店打不开？用官方下载页 →
03

注册（用网页版注册）

先到网页版注册账号，邮箱类型都可以用（QQ 邮箱、Gmail、Outlook 等均可）。

https://chat.openai.com
打开注册页面 →
04

设置身份认证器

开启两步验证，保护账号安全。手机先安装 Authenticator 类应用，再按网页提示扫码或输入密钥绑定。

手机安装 Authenticator 两步验证 扫码绑定
05

客户端登录 ChatGPT

打开客户端，选择「Sign in with ChatGPT」，用刚注册的账号在浏览器里授权登录即可。

如果登录时要求手机号验证

优先尝试：先在网页版确认账号可正常登录，再用客户端走「浏览器授权」方式登录；若仍提示需要手机验证，可按页面指引完成验证，或查看上方视频教程里的操作演示。
