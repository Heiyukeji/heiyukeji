安装方式

命令介绍网站：https://github.com/MHSanaei/3x-ui（不用看，想了解可以看看） 复制下方命令，粘贴到 SSH 中执行即可完成安装。（这是v3.8.5版本）

VERSION=v3.8.5 && bash <(curl -Ls "https://raw.githubusercontent.com/mhsanaei/3x-ui/$VERSION/install.sh") $VERSION
